# Data Dictionary: `data/processed/alberta_weekly.csv`

One row per week per season for Alberta (626 rows, 12 seasons). 8 weeks have no data and are shown as blank rows.

Blank in a count column means not reported. `pct_blank` is calculated over weeks that have data.

| Field | Type | Description | Source | Notes | % blank |
|---|---|---|---|---|---|
| `season` | text | Surveillance season, written YYYY-YYYY. A season starts in epidemiological week 35 (late August) and runs about 52 weeks. | RVDSS compilation (dajmcdon/rvdss-canada) | Taken from the name of the source file each row came from. | 0.0 |
| `epiweek` | integer (YYYYWW) | Epidemiological week as YYYYWW (year and week number). Weeks run Sunday to Saturday. | RVDSS compilation (dajmcdon/rvdss-canada) | Recalculated from time_value for every row, including weeks with no data. For weeks with data it matches the source value (QA check C06 found no mismatches). | 0.0 |
| `time_value` | date (YYYY-MM-DD) | Date of the last day (Saturday) of the surveillance week. | RVDSS compilation (dajmcdon/rvdss-canada) | Parsed to a date. Weeks with no data are added from a complete weekly calendar. | 0.0 |
| `missing_week` | boolean | True if no Alberta record exists for this week. All count and percent columns are blank on these rows. | Derived in this project | Added by building a complete weekly calendar for each season. Missing weeks are not estimated or filled. | 0.0 |
